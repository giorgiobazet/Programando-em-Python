# Programando em Python

Exercícios e anotações de estudo do curso de Python (Curso Santander), cobrindo os fundamentos da linguagem.

## Conteúdo (`Curso-Santander/`)

- Fundamentos: variáveis, tipos de dados, operadores, entrada e saída
- Controle de fluxo: condicionais e loops
- Estruturas de dados: listas, tuplas, conjuntos e dicionários
- Funções, módulos e importação
- Arquivos (leitura e escrita)
- Tratamento de exceções e exceções personalizadas

## Como executar

Requer Python 3.

```bash
cd Curso-Santander
python3 hello_world.py
```
